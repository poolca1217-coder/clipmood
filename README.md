# 클립무드

사진·영상·음악을 편집하는 무료 온라인 영상 편집기.

홈페이지: https://poolca1217-coder.github.io/clipmood/

## 기존 프로젝트 옮기기
기존 편집기에서 프로젝트 파일을 저장한 뒤, 이 사이트에서 프로젝트 불러오기로 여세요. 주소나 브라우저가 달라지면 기존 브라우저 저장소가 자동 이전되지 않습니다. 중요한 프로젝트는 파일로 보관하세요.

## 긴 영상
3시간·5시간 음악 반복 구성을 지원합니다. 실제 5시간 전체 인코딩 성공은 아직 검증하지 않았습니다. 먼저 15초 시험 저장으로 화면과 소리를 확인하세요.

## 배포
GitHub Pages: main 브랜치 / (root). index.html과 assets 폴더를 함께 배포해야 합니다. 다운로드용 HTML과 기능 코드는 같으며 배포용으로 파일만 분리했습니다.

외부 구성요소의 저작권 및 라이선스 고지는 해당 JS 파일과 THIRD-PARTY-NOTICES.txt에 보존되어 있습니다.
