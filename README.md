# 클립무드 v228

- [온라인 편집기 열기](https://poolca1217-coder.github.io/clipmood/)
- [최신 편집기 ZIP 내려받기](https://poolca1217-coder.github.io/clipmood/downloads/ClipMood-v228.zip)

## v228 변경
옵션 미리보기의 타임라인 추가·닫기 버튼을 내 컴퓨터에 저장 메뉴 바로 옆으로 옮겨 영상 위를 가리지 않게 했습니다.

타임라인 사진 선택 시 오디오 소스 파형이 가리지 않도록 수정했습니다. 사진을 선택하면 사진 미리보기로 전환하고, 오디오 카드나 탭을 다시 선택하면 파형으로 돌아갑니다.

타임라인에서 효과를 선택하고 미리보기의 주황색 모서리를 드래그하면 크기가 바뀝니다. 안쪽을 드래그하면 위치가 바뀝니다. 오른쪽 조절기와 같은 값으로 저장되며 다른 효과와 이미지에는 적용되지 않습니다.

## 내려받은 편집기 실행
ZIP을 모두 압축 풀기한 뒤 실행.cmd를 더블클릭하거나 ClipMood.html을 Chrome·Edge로 여세요.

## 기존 작업 옮기기
기존 편집기에서 프로젝트 파일을 저장한 뒤 새 편집기에서 불러오세요. 주소나 브라우저가 달라지면 저장소가 자동으로 이전되지 않습니다.

## 긴 영상
3시간·5시간 음악 반복 구성을 지원합니다. 실제 5시간 전체 인코딩 성공은 아직 검증하지 않았습니다. 먼저 15초 시험 저장으로 화면과 소리를 확인하세요.

## 배포
GitHub Pages: main 브랜치 / (root). index.html과 assets 폴더를 함께 배포합니다. 외부 구성요소의 저작권 및 라이선스 고지는 JS 파일과 THIRD-PARTY-NOTICES.txt에 보존돼 있습니다.


한 번에 만들기: 노래 → 사진 → 모양 → 옵션 추가 → 완성. 4단계에서 효과·스티커·비주얼라이저·필터·전환을 검색해 여러 개 담고 모든 사진 또는 첫 사진에 적용합니다. 옵션 없이 바로 만들어도 됩니다. 완성 후 타임라인에서 각각 편집하세요.


AI 가사 시간 맞춤 (v228)
노래를 타임라인에 넣고 ‘가사 흐르기’에서 가사를 붙여넣으세요. 언어를 고르고 ‘AI로 노래에 맞추기’를 누르면 Whisper 모델을 내려받아 이 브라우저에서 음악을 분석합니다. 처음에는 수백 MB 다운로드와 수 분 이상의 시간이 필요합니다. 음악은 서버로 보내지 않습니다. 한 곡 20분까지 지원합니다.
결과는 시간 제안입니다. ‘확인 필요’ 줄은 시작 시간을 직접 입력하거나 ±0.2초로 보정하고 해당 줄을 미리 들으세요. 적용 전 비어 있는 시간과 줄 순서를 확인합니다. 맞춘 가사는 LRC로도 저장할 수 있습니다.
실제 영어 샘플 음성에서 Whisper 단어 시간과 가사 줄 정렬을 검사했습니다. 한국어 노래 전체·모든 PC에서의 브라우저 WASM 정확도/속도는 검증하지 않았습니다. 반주·반복·발음에 따라 오차가 발생하며 음절 단위의 노래방 정밀 동기화는 아닙니다. 인터넷 연결과 최신 Chrome·Edge를 권장합니다.
